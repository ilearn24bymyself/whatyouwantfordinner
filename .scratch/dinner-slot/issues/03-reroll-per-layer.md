# 03: 每一層的「換」按鈕

**What to build:** 三層結果旁各有一個「換」按鈕，可不限次數重抽。換「吃什麼」時三層全部重抽；換「去哪吃」時保留吃什麼，重抽去哪吃與點什麼；換「點什麼」時只重新配點什麼，上兩層不變；去哪吃沒有點什麼資料時（見第 08 張票），不顯示換「點什麼」按鈕。抽籤邏輯以「要重抽哪一層」作為輸入，畫面只呼叫它並顯示結果。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 三層各有「換」按鈕，可連續重抽不限次數
- [ ] 自動測試：重抽去哪吃時，吃什麼不變
- [ ] 自動測試：重抽點什麼時，吃什麼與去哪吃都不變
- [ ] 自動測試：重抽吃什麼時，去哪吃與點什麼都屬於新抽出的吃什麼
