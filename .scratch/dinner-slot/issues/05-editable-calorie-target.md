# 05: 熱量目標可以改

**What to build:** 使用者可在設定中修改晚餐的熱量目標（預設 500 卡）。容許範圍隨之改為新目標的上下 20%，自選組合配餐與超標提醒都依新目標計算。設定保存在該裝置的瀏覽器中，下次打開仍有效；讀不到保存值時回到預設 500，畫面照常可用。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 設定中可輸入新的熱量目標，拒絕非正數等不合理輸入
- [ ] 自動測試：熱量目標改為 600 時，容許範圍為 480～720，配餐與超標判斷依此計算
- [ ] 重新整理頁面後，設定值仍保留
- [ ] 瀏覽器無法保存設定（例如無痕模式）時不報錯，回到預設 500
