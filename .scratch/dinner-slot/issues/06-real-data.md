# 06: 填入真實資料（回家路上的去哪吃）

**What to build:** 以使用者提供的真實資料取代範例資料。需求調整（2026-11-11）後，資料範圍是使用者**下班回家路上**可以拿來當晚餐的去哪吃：餐廳、小吃店、便利商店、超市，以及回家自己煮。每筆歸到一個吃什麼底下（例如麵 → 某麵店、家裡煮麵）。熱量配餐暫緩，所以**不查熱量、不填點什麼**；去哪吃只需名稱。同一家店賣兩種吃什麼時，分開登錄兩筆。

使用者口頭告知店家與類別；Claude 不自行猜測使用者路上有哪些店。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 使用者已提供吃什麼與其下去哪吃的清單（含便利商店、超市、家裡煮等，依使用者意願）
- [ ] 資料檔中每個吃什麼至少有 1 個去哪吃；去哪吃沒有點什麼資料也能正常抽籤
- [ ] 範例資料已全部移除
- [ ] 以真實資料實際抽籤多次，畫面只顯示兩層、無錯誤，抽籤邏輯的自動測試全數通過
- [ ] 完整清單給使用者過目確認
