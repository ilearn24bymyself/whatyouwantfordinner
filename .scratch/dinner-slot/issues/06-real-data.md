# 06: 填入真實資料

**What to build:** 以使用者提供的真實資料取代範例資料：住家附近的店家（例如熱滷味、冷滷味、沙威瑪、燒臘便當、麵店）與家裡常煮的東西。Claude 上網查詢每個點什麼的熱量（衛福部食品營養成分資料庫、店家公告、可信網站等），填入資料檔，並設定各去哪吃的點法、點什麼的分類與附加熱量。不記錄熱量出處。便當類等無法拆解的點什麼，以整份估計值登錄（例如三寶便當約 1000 卡）。

需要使用者提供的內容（店家清單、各店可點的東西）由使用者口頭告知；Claude 不自行猜測使用者附近有哪些店。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 使用者已提供吃什麼、去哪吃與各自點什麼的清單
- [ ] 每個點什麼都有單位與熱量；自選組合的點什麼都有分類；每個去哪吃都有點法，自選組合的去哪吃有附加熱量
- [ ] 同一家店賣兩種吃什麼時，分開登錄兩筆
- [ ] 範例資料已全部移除
- [ ] 以真實資料實際抽籤多次，自選組合的去哪吃都能產出結果，抽籤邏輯的自動測試全數通過
- [ ] 熱量數字逐項給使用者過目確認
