# 09: 只抽附近的店（核心篩選）

**What to build:** 抽籤可以接受一個「定位」（緯度、經度），只讓「附近」（以定位為圓心、半徑 3 公里的直線距離以內）的去哪吃，以及「不受距離限制」（沒有座標）的去哪吃參加抽籤；沒有任何參加者的吃什麼不參加第 1 層，其餘吃什麼等機率。不給定位時行為與現在完全相同。「換」沿用同一個定位，且仍一定換到不同的結果。本機用網址參數指定假座標（畫面上沒有入口）來驗證。同時完成資料整理，讓篩選有東西可篩：15 家有 Maps 連結的店寫入座標；「摩斯漢堡 新店安德店」改為品牌「摩斯漢堡」、不寫座標；麥當勞、漢堡王維持品牌；「回家路上的便利商店」從「麵」移出，獨立成吃什麼「便利商店」，底下放「便利商店」；「麵」只剩邱家川味涼麵。詳見規格 `.scratch/dinner-slot/spec-nearby.md`。
