# 11: 手機定位與「只抽附近」開關

**What to build:** 首頁多一個「只抽附近的店」開關，預設開。開啟時，使用者按下「直接給答案」或「一步一步來」才取得手機定位（不是一打開網頁就詢問）；取得成功就把定位交給抽籤，之後的「換」沿用這次的定位。取得失敗（拒絕、沒開定位、抓不到）時顯示「抓不到位置」提示，並退回全部店參加抽籤。開關關閉時完全不要求定位，行為與現在相同。定位只在手機上使用，不傳出、不記錄。網址有指定假座標時，改用假座標，不要求真實定位（本機測試用）。

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 首頁有「只抽附近的店」開關，預設開，不需要記住狀態
- [ ] 開關開啟時，按下「直接給答案」或「一步一步來」才取得定位，頁面載入時不詢問
- [ ] 定位成功：用該位置篩選抽籤；之後的「換」沿用同一位置，不再詢問
- [ ] 定位失敗：顯示「抓不到位置」提示，並從全部店抽籤，不卡住
- [ ] 開關關閉時不要求定位，從全部店抽籤
- [ ] 網址有假座標時用假座標，不要求真實定位
- [ ] 瀏覽器（本機）實際操作：開關開／關、有假座標、定位被拒絕（以模擬方式）三種情況行為正確；一次抽完與逐層抽都正常；手機寬度版面不跑版，沒有錯誤訊息
- [ ] 手機真實定位的實測，待第 07 張票上線後在 https 網址進行（不在本票範圍）
