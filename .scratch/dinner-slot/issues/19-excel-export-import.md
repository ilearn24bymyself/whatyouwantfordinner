# 19: Excel 匯出匯入

**What to build:** 兩個雙擊檔案：匯出把資料檔變成 Excel（一家一列：類別、店名、連鎖、行政區、地址、座標、營業時間、公休）；匯入讀 Excel（.xls 或 .xlsx）更新資料檔，以 Excel 為準、店名為身分，含刪除。匯入前顯示新增、更新、刪除各幾家，確認才寫入；有錯誤時列出哪一列哪一欄、整份不寫入；寫入前備份原檔。

**Blocked by:** 18

**Status:** ready-for-agent

- [ ] 自動測試：匯入計畫（新增、更新、刪除、沒變）正確
- [ ] 自動測試：錯誤清單（連鎖外沒行政區、行政區格式、座標、營業時間）指出列與欄，且有錯就不產生寫入結果
- [ ] 自動測試：匯出再匯入，資料檔內容完全相同（無新增、更新、刪除）
- [ ] 實檔驗證：用小型 xlsx 與 xls 各跑一次
- [ ] 雙擊檔案可用（匯出、匯入），中文不亂碼，.bat 遵守專案規則
- [ ] 現有自動測試全數通過
