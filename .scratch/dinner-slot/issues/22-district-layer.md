# 22: 抽籤多一層「區」

**What to build:** 抽籤最前面多一層「區」：區 → 吃什麼 → 去哪吃。區依目前符合條件的店數加權，連鎖店歸在「不限地點」。所有篩選（行政區標籤、只抽附近、連鎖開關、營業時間）照舊生效，區自然只在符合條件的店所在的區裡抽。「換」可以只重抽區、吃什麼或去哪吃，保留上面各層且一定不同。逐層抽的第一步變成區。詳見 `.scratch/dinner-slot/spec-district-reel.md`。
