# 規格：拉霸機的「區」與動畫呈現

## 問題

使用者有時想去外地吃飯，但抽籤沒有「去哪個區」這一層；而且結果是直接顯示，沒有拉霸機的樂趣，也看不到「減肥中」之類的提醒。

## 解法

1. 抽籤最前面多一層「區」：區 → 吃什麼 → 去哪吃（→ 點什麼）。區依符合條件的店數加權，連鎖店歸在「不限地點」一格。
2. 「直接給答案」改成大字跳動的動畫（示範 C 版）；「一步一步來」保留，不加動畫。
3. 畫面最上方有固定的「招牌」，抽完結果下方有「結果提示」，兩段文字放在設定檔，使用者自己改。

## 使用者故事

1. 身為使用者，我想抽籤時連「區」一起抽，這樣想去外地吃時，機器會告訴我去哪個區
2. 身為使用者，我希望店多的區機率高，這樣不會一直抽到只有一家店的區
3. 身為使用者，我希望連鎖店也能被抽到，所以區那一軸有「不限地點」
4. 身為使用者，我選了行政區標籤時，區只會在那幾區裡抽
5. 身為使用者，「只抽附近」開著時，區只會出現附近有店的區
6. 身為使用者，我想只重抽區、只重抽吃什麼、或只重抽店，而且一定換到不同的
7. 身為使用者，我想看到大字跳動後依序停下的動畫，點一下可以立刻停
8. 身為使用者，手機開了「減少動態效果」時，我希望直接看到結果，不要跳動
9. 身為使用者，我想一進來就看到「減肥中」招牌，抽完還有一行提醒
10. 身為使用者，我想自己改招牌與提示的文字，或留空不顯示

## 實作決定

- 層：`LAYERS = ['district', 'meal', 'place', 'items']`；`draw` 的 `reroll` 多一個 `'district'`，其下各層跟著重抽（沿用既有規則）。
- 區的決定方式：先照目前所有篩選（行政區、定位、連鎖開關、營業時間）算出符合條件的店，再依「區」分組、依店數加權抽一個區；連鎖店（沒行政區）歸在「不限地點」組，同樣依店數加權。抽到區之後，該區裡的「吃什麼」等機率、再等機率抽店（與現有規則相同）。
- 結果多一個欄位表示區：行政區顯示區名，連鎖店顯示「不限地點」。
- 「換」：換區＝三層重抽；換吃什麼＝保留區；換去哪吃＝保留區與吃什麼。上一次的區已不符合條件時，視為重抽。
- 揭曉節奏（逐層抽）：區是第一層；沒有「點什麼」資料的店仍然只有三層。
- 動畫：大字跳動，越來越慢停下，區、吃什麼、去哪吃依序停，整體最長約 3 秒；點一下可立刻停；開了「減少動態效果」就不跳。抽籤結果在動畫開始前就已決定，動畫只是顯示。
- 招牌與結果提示：兩段文字放在 `data/settings.json`（鍵 `sign`、`after`），留空或沒有這個檔就不顯示；管理頁暫不能編輯，先改檔案。「轉動時混入自訂文字」的舊做法不做。
- 抽籤規則一樣只透過 `draw(...)` 測試；畫面不測規則。

## 測試決定

- 只測外部行為：給定資料與選項，抽到的區是否符合條件、加權是否照店數、連鎖店歸入「不限地點」、各種篩選下區的範圍、各層「換」是否保留該保留的並且一定不同。
- 沿用現有 `draw(...)` 的測試寫法與固定亂數；資料檢查測試不變。

## 不做

- 聲音、震動、轉動時混入自訂文字、管理頁編輯招牌文字、依使用者所在位置自動決定區。
